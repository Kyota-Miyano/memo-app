# テスト仕様書 （宮野チーム）

すべての機能要件（F-01〜F-09）に、1件以上のテストケースを対応させています。

## テスト方針と環境

* **API テスト**: `curl` や REST クライアントで実行する。
* **画面テスト**: ブラウザで手動確認する。リアルタイム同期は、2つのブラウザ（端末A・端末B）を同時に開いて確認する。
* **前提の記号**: 「メモ $N$ 件」は、未削除のメモがその件数あることを指す。

## 合格基準

* 上記のすべてのケースが「期待結果」のとおりになる。ただし `T-API-05` と `T-API-06` は、現行実装の結果（`500`）を期待値とする。
* 重大な不具合（データの消失、他端末への誤った反映）が残っていない。
* **既知の制約**: 入力制限の違反は、`400` ではなく `500` で返る。`400` に改善する場合は、`T-API-05`・`T-API-06` の期待結果を更新する。
