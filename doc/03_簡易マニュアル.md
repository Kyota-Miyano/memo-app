# メモ帳SPA 簡易マニュアル

## 1. アプリの概要

メモ帳SPAは、ブラウザからメモを作成・保存・編集・削除できるアプリケーションです。保存したメモは一覧に表示され、更新日時・作成日時・タイトルで並び替えることができます。

## 2. アプリの起動

開発環境の起動手順に従って、Docker、バックエンド（Express）、フロントエンド（Vite）を起動してください。

ブラウザで次のURLを開きます。

```text
http://localhost:5173/
```

## 3. 画面の見方

| 画面の項目 | 説明 |
|---|---|
| 左側のメモ一覧 | 保存済みメモのタイトルと更新日時が表示されます。 |
| `＋ 新規` | 新しいメモを作成するときにクリックします。 |
| 並び替え | メモ一覧の表示順を選択します。 |
| `タイトル` | メモのタイトルを入力します。最大100文字です。 |
| `本文` | メモの内容を入力します。最大10,000文字です。 |
| `保存` | 新規メモの登録、または選択中のメモの更新を行います。 |
| `削除` | 選択中のメモを削除します。新規作成中は使用できません。 |
| ステータス表示 | 未保存、保存中、保存完了などの状態が表示されます。 |

## 4. メモを新規作成する

1. 左側の `＋ 新規` をクリックします。
2. `タイトル` にメモのタイトルを入力します。
3. `本文` にメモの内容を入力します。
4. `保存` をクリックします。
5. 「保存しました。」と表示され、左側の一覧にメモが追加されたことを確認します。

**タイトルを空欄にして保存した場合**は、`メモ(YYYY-MM-DD)` の形式でタイトルが自動設定されます。日付は日本時間です。

## 5. 保存済みのメモを編集する

1. 左側の一覧から編集したいメモをクリックします。
2. 右側に表示されたタイトルまたは本文を変更します。
3. `保存` をクリックします。
4. 「保存しました。」と表示されたことを確認します。

保存すると、メモの更新日時も更新されます。

## 6. メモを削除する

1. 左側の一覧から削除したいメモをクリックします。
2. `削除` をクリックします。
3. 「このメモを削除しますか？」という確認が表示されます。
4. 削除する場合は `OK`、取り消す場合は `キャンセル` を選択します。
5. 削除が完了すると「削除しました。」と表示され、一覧からメモが消えます。

削除は論理削除として処理されます。通常の画面からは表示されなくなります。

## 7. メモ一覧を並び替える

左側の並び替えメニューから、次の6種類を選択できます。

| 選択肢 | 並び順 |
|---|---|
| 更新日時：新しい順 | 最近更新したメモから表示します。 |
| 更新日時：古い順 | 更新日時が古いメモから表示します。 |
| 作成日時：新しい順 | 最近作成したメモから表示します。 |
| 作成日時：古い順 | 作成日時が古いメモから表示します。 |
| タイトル：昇順 | タイトルを日本語（`ja`）の照合順で昇順に表示します。 |
| タイトル：降順 | タイトルを日本語（`ja`）の照合順で降順に表示します。 |

並び替えは一覧の表示順だけを変更します。メモの内容や保存日時は変更されません。

## 8. 未保存の変更と下書き

タイトルまたは本文を変更すると、ステータス欄に「未保存の変更があります。」と表示されます。

編集中の内容は、ブラウザのLocalStorageに下書きとして一時保存されます。

### 別のメモへ移動するとき

未保存の変更がある状態で別のメモをクリックしたり、`＋ 新規` をクリックしたりすると、変更を破棄して移動するか確認が表示されます。

- `OK`：変更を破棄して移動します。
- `キャンセル`：移動せず、現在の編集内容を残します。

### ページを再読み込みしたとき

復元可能な下書きがある場合、「前回編集中だったメモがあります。復元しますか？」と確認が表示されます。

- `OK`：下書きの内容を入力欄に復元します。
- `キャンセル`：下書きを削除し、復元しません。

保存が完了すると、その下書きは削除されます。下書きはブラウザ・タブごとに保存されるため、別のPCや別ブラウザへ自動的に引き継がれるものではありません。

## 9. 複数のタブ・ブラウザでの同期

同じアプリに複数のタブまたはブラウザから接続している場合、一方で行ったメモの作成・更新・削除が、別の接続先の一覧に通知されます。

- **別の接続先でメモが作成された場合**：一覧に新しいメモが追加されます。
- **選択中のメモが別の接続先で更新された場合**：自分が編集していなければ最新の内容が反映されます。
- **選択中のメモを編集中に別の接続先で更新された場合**：編集中の内容は上書きされず、別のタブで更新されたことがステータス欄に表示されます。
- **選択中のメモが別の接続先で削除された場合**：削除されたことがステータス欄に表示されます。編集中の入力内容は自動的に消されません。

WebSocketが切断された場合、自動再接続は行われません。バックエンドが復旧した後、ブラウザを再読み込みしてください。

## 10. 入力時の注意

- タイトルは最大100文字です。
- 本文は最大10,000文字です。
- タイトルが空欄または空白のみの場合、保存時に日付入りのタイトルが自動設定されます。
- 保存する前に画面を移動すると、確認に応じて未保存の変更が破棄される場合があります。
- 下書きはブラウザ内に一時保存されます。重要な内容は必ず `保存` をクリックしてください。

## 11. 困ったときは

| 状況 | 確認すること |
|---|---|
| メモ一覧が表示されない | バックエンドとデータベースが起動しているか確認し、ページを再読み込みしてください。 |
| 保存に失敗する | バックエンドの起動状態を確認してください。タイトル・本文の文字数も確認してください。 |
| 削除できない | 一覧から対象のメモを選択しているか確認してください。新規作成中は削除できません。 |
| 別のタブに変更が反映されない | WebSocket接続とバックエンドの状態を確認してください。復旧後、ブラウザを再読み込みしてください。 |
| 下書きが復元されない | 同じブラウザ・同じタブで開いているか確認してください。下書きをキャンセルした場合や対象メモが削除済みの場合は復元されません。 |

---

以上が、メモ帳SPAの基本的な操作方法です。
